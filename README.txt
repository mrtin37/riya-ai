RIYA PHONE-FIRST WEB APP
========================
This is a single-file Riya prototype.

How to use:
1. Open index.html in a browser that can access local HTML files, or upload it to any static web host.
2. On Android Chrome, allow microphone access when prompted.
3. Use the microphone button to speak.
4. Use Chrome's menu > Add to Home screen to make it feel like an app.

Current features:
- Futuristic Riya UI
- Voice input using Web Speech API
- Text-to-speech
- Local chat memory using localStorage
- Basic demo response brain

Next:
